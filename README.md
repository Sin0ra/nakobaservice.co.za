# Nakoba Services Website

A static business website developed for Nakoba Services to give the
business a professional online presence and make it easier for customers
to find information and send enquiries.

## Project Overview

This project was developed as a client website and includes business
information, service presentation and a customer contact form.

## My Role

I was responsible for the website development and technical setup,
including:

-   Designing and developing the static website.
-   Building pages using HTML and CSS.
-   Adding JavaScript functionality where required.
-   Adding and configuring the customer contact form.
-   Setting up the website domain.
-   Setting up and configuring hosting through Hostinger.
-   Creating and configuring business email accounts for the client.
-   Testing the website and resolving setup issues before the site was
    made available to the client.

## Technologies Used

-   HTML
-   CSS
-   JavaScript
-   PHP
-   Hostinger
-   Domain and DNS configuration

## Website Features

-   Business information and service sections
-   Responsive website layout
-   Customer contact form
-   Business contact details
-   Search-engine related files such as `robots.txt` and `sitemap.xml`

## Development Approach

AI tools were used as a development and learning aid during parts of the
project. They helped with researching solutions, understanding
unfamiliar concepts and troubleshooting. I reviewed, tested and adapted
the resulting code and remained responsible for the final implementation
and setup.
